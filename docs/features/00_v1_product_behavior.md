# 00_v1_product_behavior.md - StickyMD v1 用户可见行为

> 本文是 `docs/plan/` 的用户视角投影。只描述用户能观察到的行为。
> 契约细节以 plan 为准；验收案例见 `docs/acceptance-cases/00_v1_acceptance.md`。

---

## 第一次运行

1. 把 `StickyMD.exe` 放进任意可写文件夹（例如 `D:\Notes\MathScratch\`）。
2. 双击运行。程序自动创建 `note\` 目录：`note.md`、`config.toml`、`images\`、`.trash\`。
3. 窗口出现（默认源码模式、Light 主题、96% 透明度、520×680）。
4. 直接开始输入。内容自动保存。

如果文件夹不可写，程序提示“当前目录不可写，请将程序移动到有写权限的文件夹。”并退出。
需要第二张便签：把整个程序文件夹复制到别处再运行；两张便签互不干扰。
同一个文件夹双击两次只会唤醒已打开的那一张。

## 输入 Markdown

- 所见即源码：你看到并编辑的就是 Markdown 原文。
- 中英文混排自动切换字体（中文仿宋_GB2312、英文 Times New Roman、代码 Consolas）。
- 中文输入法（微软拼音、微信输入法）可正常使用：候选框跟随光标，
  提交后一次 Ctrl+Z 可整体撤销。
- Ctrl+Z / Ctrl+Y 撤销重做；Ctrl+C / Ctrl+V 复制粘贴文本。

## 三种视图

- **源码**：编辑 Markdown 原文。
- **预览**：只读渲染结果；可以选中文字、Ctrl+C 复制、滚动、点击链接。
- **分栏**：左源码右预览，固定各占一半，分隔线不可拖动，两边各自滚动。

## 数学公式

- 支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 四种写法，语法与 KaTeX 兼容。
- 预览中输入停顿约 1 秒后自动刷新。
- 公式写错不会崩溃：显示原始公式文本并给出轻微错误提示。
- 在预览中选中公式复制，得到的是公式源码。

## 图片粘贴

- 复制图片（截图或图片文件）后 Ctrl+V，图片自动保存到 `note\images\`
  并在光标处插入引用。
- 删除图片引用后，图片进入回收区 `.trash\`；Ctrl+Z 撤销删除会把图片恢复回来。
- 你自己放进 `images\` 的图片永远不会被程序删除。
- 网页图片链接不会被下载，预览只显示替代文字和链接。

## 自动保存

- 停止输入约 0.65 秒后自动保存；Ctrl+S 立即保存。
- 窗口失焦、最小化到托盘、退出时也会保存。
- 保存永远不会产生半截文件；即使程序被强制结束，下次启动也能发现未完成保存
  的内容并让你选择是否恢复。

## 外部修改

- 用别的编辑器修改了 `note.md`：若你当前没有未保存内容，程序自动载入新内容。
- 若你有未保存内容，程序显示提示条“文件已在外部修改”，让你选择
  [载入外部] 或 [保留本地]；不会偷偷覆盖任何一边。

## Undo / Redo

- 仅本次运行期间有效；关闭程序后清空。
- 历史容量有限（自动淘汰最旧条目），不影响正常使用。

## 导出

- Ctrl+Shift+S 打开“导出”：选择目标位置后，程序复制 Markdown 与其中引用的图片
  到 `<文件名>-assets\` 文件夹。工作文档本身不变。

## 窗口行为

- **置顶**：窗口始终保持在其他窗口之上（可随时关闭）。
- **透明度**：70–100 可调，整窗半透明。
- **贴边隐藏**：把窗口拖到屏幕左/右/上边缘附近松手，窗口会收起成一条细边；
  鼠标碰触细边即展开。正在打字时绝不自动收起；按 Esc 或收起按钮可随时手动收起。
- **关闭按钮**：点击窗口关闭只是隐藏到托盘，程序继续运行。
- **托盘**：右键托盘图标只有“显示/隐藏”“置顶”“退出”三项；只有“退出”会真正结束程序，
  退出前一定先保存。

## 主题

- 三种：Light（默认）、System（跟随 Windows 明暗）、Dark。
- 切换立即生效；Windows 换主题时 System 模式跟随变化。

## 多显示器

- 可以把便签放在任意显示器上并贴边隐藏。
- 混合缩放比例（DPI）的显示器、拔掉显示器、睡眠唤醒后，窗口都会出现在
  可见位置，不会跑到屏幕外。
