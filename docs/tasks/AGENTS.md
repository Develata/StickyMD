# docs/tasks/AGENTS.md

`docs/tasks/` 存放阶段实施计划与完成状态记录。

规则：

- 每个阶段一个文件：`phase-NN-<slug>.md`。
- 必须包含：Goal / Scope / Inputs / Deliverables / Verification / Out of Scope /
  Completion State。
- Completion State 只允许：`In Progress` | `Completed` | `Blocked`。
- 声称 `Completed` 前必须完成该阶段全部验证项，并且不得夸大：
  未实现的能力不得写成已具备。
