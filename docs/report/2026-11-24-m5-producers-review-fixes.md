## 需要 Develata 决定

**F7：怎样确认资源测量的每个场景确实以所配置的视图打开。** `mac-resources` 给 Source、Preview、Split 三个场景写不同的 `view_mode`，
但只确认产品进程有一个足够大的窗口。产品若忽略配置，三组 Source 的测量会被当作三个场景计数；Preview 与 Split 的内存门更宽，忽略配置只会让

**在你决定之前（已实现，fail closed）：** R01、R02 都不判 PASS。运行完整、读数都在门内时，这一行记为 `NOT_TESTED`，原因写明“没有运行确认它的场景以所配置的视图打开”；
`FAIL` 照常记为 `FAIL`。`mac-resources` 在这种情况下仍以 0 退出，表示测量本身成立。账本照此登记，发布门对这两行判 `NOT_TESTED`，可由你 waiver。

### B9 的实现：kqueue 写入观测

提交 `7e5eb45`。

- **观测**（`mac_gui/native/vnodes.rs`）：打开产品之前，以 `O_EVTONLY | O_NOFOLLOW` 打开被观察文件夹中的每一项，在一个 kqueue 上登记
  `EVFILT_VNODE`（`EV_RECEIPT` 逐个核对登记结果）。然后取运行前的快照，登记的条目须与快照的条目相同。本次的进程都结束之后、取运行后的
  快照之前，以零超时读空队列。常量与 `struct kevent` 的布局取自 SDK 的 `sys/event.h` 与 `sys/fcntl.h`，测试核对布局。登记或读出失败是 R03
  的错误，整次运行停下。
- **判定**（`mac_gui/translocation.rs`，纯函数）：快照不同为 FAIL；有写、扩展、链接数变化、改名或删除为 FAIL；没有观测、登记不全或有条目被撤销为
  `NOT TESTED`；属性变化只记下。这一项改名为“nothing written in the folder holding the package (kqueue and snapshots)”，只比快照的旧检查表
  （例如 `m5p-2`）不能再登记为 PASS。

### 需要 Develata 决定：R02 的 60 s 窗口（B3）

`10` 的硬门是“60 s 平均 > 0.1%”。驱动在第一次采样之后睡 60 s 再采第二次，第二次总会晚到一点（虚拟机里至多 20 ms，允许 0.5 s）。两次采样之间的 CPU 时间不超过 60 ms 时，其中任一个 60 s 窗口都不超过硬门，所以“成立”可以证明；但窗口长于 60 s 时，两次采样说不出 CPU 花在哪一段，不能证明有某个 60 s 窗口超过。现在的过渡规则因此只在窗口恰为 60 s 时判 FAIL；实际运行几乎总是晚到，所以超过硬门的场景在过渡规则下只能为 `NOT TESTED`，而 R02 的 `NOT TESTED` 可以 waiver。

| 办法 | 做法 | 代价与风险 |
| --- | --- | --- |
| A（建议）第三次采样 | 在 60 s 之前（例如 59.9 s）再采一次。下界取自它（不到 60 s 的窗口中的 CPU 不多于这个 60 s 窗口），上界取自 60 s 之后那次。超过下界即 FAIL，不超过上界即成立，只剩两次采样之间约 0.1–0.5 s 的 CPU 无法判定 | 驱动、读器与证据格式（schema 6）都要改，`mac-resources` 要在虚拟机中重跑；视图诊断分支的 schema 顺延 |
| B 记录 CPU 核数 | 下界取 C − 核数 × (W − 60)，不改采样 | 晚到 20 ms、4 核时，C 超过 140 ms（硬门的两倍多）才判 FAIL，略超硬门的场景仍为 `NOT TESTED` |
| C 改条款 | 硬门改为“所测窗口（60–60.5 s）的平均” | 改动 `10` 与 `11` 的措辞，偏离“60 s 平均”至多 0.8%；判定回到第二轮的做法 |

建议 A：它不改条款，成立与 FAIL 都有证明，剩下的无法判定区间很窄。

**Resolution（USER 2026-11-24，原话）：** “A：第三次采样”。实现：驱动在第一次采样之后 59.9 s 再采一次（`model::LOWER_SAMPLE_SECONDS`），证据升为
schema 6，有效运行恰有三次采样；判定的下界取自第一次到中间一次（中间一次落在 60 s 之内时），上界取自第一次到最后一次，都按原始计数精确比较。
条款见 plan 11 #phase-16-macos-host 的 R02。过渡规则（只在窗口恰为 60 s 时判 FAIL）随之取消。
