# Phase 15 D 之后的 Windows 桌面回归

日期：2026-11-08。这是一次本地回归的记录，不是 exact-candidate 资格化证据。

## 被测对象

- 产品代码：`b7b5980`（其后到本报告的提交只改文档与测试工具）。
- Release 二进制：`stickymd-win.exe`，SHA-256 `38a343b73b6a5031a7db861266b20103810c2396de2c0a448aec2dcee0a69e87`，8,689,664 字节。
- 环境：Windows 11，单块 2560×1440、100% 显示器；微软拼音与微信输入法。

## 方法

脚本部分用仓库自带的本地预检：`STICKYMD_PREFLIGHT_EXE` 指定二进制，在干净 worktree 里逐个以 `--ignored --exact --test-threads=1` 运行，真实窗口、真实输入。脚本判断不了的项由 USER 用同一二进制人工检查。

G3-02 在启动后的第一个动作（激活点击）读不到左键按下，之后前台停在 `GameInputServiceWindow`。基线 `ae09b67` 的二进制在同一处失败，所以不是 Phase 15 的回归；根因未查清。

第一轮有 5 个用例因测试工具仍等待工具栏空白的手形光标而停在第一步。C3 起那里是箭头（预期差异 8b），工具已修正（`3022ff1`），修正后这些用例通过。

环境因素：桌面上没有可接手的普通窗口时，前台会落到 `GameInputSvc` 的窗口，Windows 随后拒绝注入的光标移动。受影响的用例在前台可用时重跑。
