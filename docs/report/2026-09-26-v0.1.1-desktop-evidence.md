## 根因与修复

共享 smoke runner 已收集失败结果，却在最终 `evidence::emit` 之前返回。这影响 task
错误、性能门槛失败、不可用环境和最终治理检查失败，也使本次正式启动测量收集到的
milestone 数据无法进一步分析。

现在任务执行统一返回证据收尾阶段：失败时先原子写出已收集结果，再返回原始错误。
若证据写入也失败，同时报告两项错误。失败后的后续任务仍不执行。只有非空且全部
`PASSED` 的结果才能更新 last-success ledger；失败诊断的写入不依赖有效的候选成功记录。

JSON 模式下，runtime 的逐样本和进度诊断改写到 stderr，stdout 继续保持机器可读。
即使某个 runtime 场景在返回结构化结果之前报错，已输出的中间测量也可保留在日志中。

startup attribution 原先无条件输出 `NO PRODUCT OPTIMIZATION NEEDED`。现在明确只报告归因，
门槛结论仍由 Performance receipt 持有，不自动推断产品不需要优化。
