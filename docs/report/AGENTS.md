# docs/report/AGENTS.md

`docs/report/` 存放**有时间属性的分析证据**，不是长期权威。

规则：

- 典型文件：
  - `RISK-<topic>.md`：技术风险报告（Agent Stop Conditions 触发时产出）。
  - `phase-NN-<topic>.md`：阶段分析/冲突/架构疑问报告。
- 报告必须包含：重现步骤/背景、根因或问题陈述、已尝试方案、数据、
  可选路径、对规格的影响。
- 骨架级结论只有经 USER 批准并落盘到 `docs/plan/` 后才成为契约；
  报告本身**永远不是契约**。
- 报告不得回改；结论被采纳或否决时可在文末追加 `Resolution` 小节并注明日期。
