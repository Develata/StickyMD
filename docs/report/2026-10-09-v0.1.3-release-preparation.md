## 验证方法与状态

按 [release checklist](../release-checklist.md) 和
[plan 11](../plan/11_testing_and_release.md#release-artifact-authority) 建立 clean Source Freeze，
执行适用基线和 source preflight，推送后核验新 source 的 CI，再显式运行 `release.yml`。
记录唯一 run/attempt/artifact id；由 Rust CLI 按该身份独立下载，核对 ZIP、checksum、SBOM、
source/version、包成员、许可证、PE imports 与 portable runtime，成功后才 Promote。

本记录在 Source Freeze 前提交，此时新 source 的动态验证尚未执行。实际 source、run、哈希、
命令日志和 readiness 保存在隔离 worktree 的 ignored `dist/evidence/`，避免回写冻结 source。
人工验收未执行，保持 `NOT TESTED`；候选成功不等于 `READY`。
