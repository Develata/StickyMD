# StickyMD Release Checklist

## Automated gates

- [ ] Exact clean commit built with `cargo build --workspace --release --locked`.
- [ ] `cargo fmt`, strict Clippy, workspace tests, `cargo deny check`, and `tools/smoke/all.ps1 -Ci` pass.
- [ ] Phase 9 performance and resource report names the exact EXE SHA-256.
- [ ] Portable ZIP passes `tools/release/verify-package.ps1`.
- [ ] `SHA256SUMS.txt` covers the ZIP and `SBOM.spdx.json`.
- [ ] SPDX SBOM was generated by the pinned, checksum-verified Syft version.
- [ ] Release workflow syntax/static security audit passes; remote workflow evidence is recorded separately.

## Manual gates

- [ ] Every release-blocking `NOT TESTED` row in `docs/acceptance-cases/phase-09.md` has a current-artifact receipt, or an explicit USER waiver.
- [ ] Microsoft Pinyin and WeChat IME matrix.
- [ ] Light/Dark/System, opacity, Preview/math/image visual matrix.
- [ ] Tray, three docking edges, hover timing, DPI and real multi-monitor topology.
- [ ] Clipboard sources, export dialog, hard-kill recovery, junction/symlink and clean Windows 11 VM.

## USER decisions

- [ ] Approve the release version; do not infer `1.0.0` from the v1 product name.
- [ ] Approve any cold-start waiver above the 300 ms optimization target; values above 400 ms remain blocking.
- [ ] Approve every remaining manual waiver individually.
- [ ] Decide whether the unsigned-build policy is acceptable or provide a real code-signing certificate.
- [ ] Approve pushing the exact commit and tag.

## GitHub draft release

- [ ] Confirm the tag version exactly matches the workspace version and its commit belongs to the approved branch.
- [ ] Confirm the remote release workflow passed for the exact tag SHA.
- [ ] Download artifacts; verify `SHA256SUMS.txt` and run `gh attestation verify <artifact> --repo <owner/repo>`.
- [ ] Re-run the portable smoke on the downloaded ZIP and a clean Windows machine.
- [ ] Inspect the generated draft release and release notes.
- [ ] Publish the draft only after explicit USER approval.
