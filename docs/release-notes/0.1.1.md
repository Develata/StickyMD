# StickyMD 0.1.1

本版本包含长文滚动、剪贴板提示、渲染与撤销修复，以及开发验证和发布工具改进。
正式发布状态以 GitHub 的同名 tag 和 Release 为准；本文不替代候选产物验收记录。

## 使用体验

- Source 和 Preview 均增加可拖动的垂直滚动条；Split 中两栏各有一条。
  长文时细滑块常驻，鼠标进入滚动条区域时加粗，方便迅速定位到文首、文尾或中间位置。
- Split 保留既有同步滚动开关；开启时两栏联动，关闭时可独立滚动。
- 剪贴板成功提示不再长期占据源码底部的诊断栏；实际错误仍通过诊断栏显示。
- 快速拖动、反向滚动、缩放和调整窗口时，过期预览结果不会接管当前视口交互。

## 正确性与性能

- 修复撤销合并的时间边界和换行边界。
- 修复 Markdown 表格转义竖线的源码范围映射。
- 限制活动光栅缓存并安全跳过视口外的预览行，减少长文滚动时的重复工作。
- 增加源码滚动和预览交互回归，以及对应的性能基线检查。

## 开发与发布工具

- Rust CLI 统一管理模块化验收任务、依赖影响选择、发布校验、许可证清单和 SBOM 规则。
- GitHub CI 并发运行适用模块，保留任务计划与模块诊断；性能测试在各分片内串行执行。
- SBOM 生成先写临时文件并校验，失败时保留既有输出；完成后逐文件原子替换。
- 补齐 Linux smoke CLI 检查和 Windows PowerShell 5.1/7 路径兼容性回归。

## 运行与升级

- 支持 Windows 11 x64，以 portable ZIP 分发；程序目录需要允许当前用户写入。
- 升级前保存并退出旧实例，保留原目录的 `note/`；不要用空白便签覆盖已有数据。
- 产品仍为一张 Markdown 草稿，无网络客户端、云同步、遥测、自动更新或 WebView。
- 延续 unsigned Authenticode 分发方式，Windows 可能显示 SmartScreen 或信誉提示。
  请从官方 Release 获取文件，并用 `Get-FileHash -Algorithm SHA256` 对照随附
  `SHA256SUMS.txt`；不要关闭系统防护。发布资产的来源还可通过 GitHub attestation 核验。

## 验收边界

普通 CI 验证无界面的构建、测试及性能基线。正式版本还需绑定远端候选产物，完成适用的
Runtime、Performance、Resources、G3/G4/G5 和人工验收。真实输入法候选窗视觉、物理多屏/DPI、
Clean Windows 11 VM 等项目不能由普通 CI 推断通过，也不继承 `v0.1.0` 的人工豁免。
每次验收结果、明确接受的风险及未验证项目须随本版本的发布记录披露。
