# StickyMD 0.1.3

本补丁改进现有 `$` 数学转换按钮：在完整的 `$$...$$` 公式块内，将夹在相邻非空
表达式行之间、独占一行的裸 `=` 连接起来。例如三行 `a`、`=`、`b` 转为 `a=b`，
连续推导可转为 `a=b=c`。分隔符转换与等号连接合起来只需一次撤销。

- 有选区时只处理完整落在选区内的公式块；无选区或纯预览时处理整篇。
- 不跨空行或公式块；行内公式、代码、块首尾或连续的孤立等号、`\=` 和其它运算符保持原文。
- 含注释、显式 LaTeX 换行或结构环境的块保守跳过；重复点击不重复修改已连接的文本。

Windows 11 x64 portable，沿用 unsigned Authenticode 形式。升级前保存、退出旧实例并备份
原目录的 `note/`。正式资产如获后续发布授权，应从官方 Release 下载，并用
`Get-FileHash -Algorithm SHA256` 核对 `SHA256SUMS.txt`，同时核验来源证明；无需关闭系统防护。

本次范围仅到候选验证和满足门槛后的 tag；尚未授权正式 Release。CI、候选构建、精确包验证
与桌面/人工验收是不同证据。未执行项保持 `NOT TESTED`，不继承 v0.1.2 的验收特例。
