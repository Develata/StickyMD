# StickyMD 0.1.3

本维护版本改进密集公式与宽内容的阅读、预览资源管理、查找替换和输入法交互，并保留
现有 `$` 数学转换按钮的独立等号行修复。

## 预览与资源占用

- 公式的布局尺寸与位图分开管理，优先生成可见区域附近的位图；缓存满时回收并按需重新生成，
  支持规模内的正常公式不会因为整篇位图缓存耗尽而永久变成错误占位。
- 宽表格、长代码行和超宽块公式可以横向滚动；短公式保持居中，选择与复制保留原文语义。
- 预览文字初始化省去空文本的重复排版；同一轮图片请求合并，缓存校验减少大块临时分配，
  保留外部图片修改、删除后的正确刷新。
- 字形位图与公式布局缓存增加明确的预算和回收边界。开发期测量用于发现回归，
  不把局部测试结果表述为所有文档、机器上的固定性能提升。

## 输入、查找与窗口交互

- 查找面板在 Preview 模式暂存状态，恢复 Source/Split 后继续定位；替换只作用于当前选中的
  活动匹配，并从插入文本之后选择下一处匹配。输入法组合期间保留候选操作按键。
- 查找面板在窄 Source 栏采用紧凑布局，保持固定 40% 透明度。
- 修复输入法处理过的按键被误当成窗口快捷键的问题，并统一 Esc、滚动条和透明度控件的行为。
- 再次点击透明度按钮可关闭弹窗；数值输入按既有规则提交整数。再次启动同一便签时，
  已收起的贴边窗口能够展开。

## 数学转换

在完整的 `$$...$$` 公式块内，将夹在相邻非空
表达式行之间、独占一行的裸 `=` 连接起来。例如三行 `a`、`=`、`b` 转为 `a=b`，
连续推导可转为 `a=b=c`。分隔符转换与等号连接合起来只需一次撤销。

- 有选区时只处理完整落在选区内的公式块；无选区或纯预览时处理整篇。
- 不跨空行或公式块；行内公式、代码、块首尾或连续的孤立等号、`\=` 和其它运算符保持原文。
- 含注释、显式 LaTeX 换行或结构环境的块保守跳过；重复点击不重复修改已连接的文本。

## 下载、运行与升级

下载本 Release 的 `StickyMD-0.1.3-windows-x64-portable.zip`，解压后运行 `StickyMD.exe`。适用于 Windows 11 x64，无安装器。升级前保存并退出旧实例，备份原目录的 `note/`。

程序未做 Authenticode 签名，Windows 可能显示未知发布者或信誉提示。请从此官方 Release 下载，并核对下面的校验和及来源证明；无需关闭系统防护。
