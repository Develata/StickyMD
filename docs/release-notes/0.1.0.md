# StickyMD 0.1.0

发布日期：2026-08-30

发布页面：[StickyMD v0.1.0](https://github.com/Develata/StickyMD/releases/tag/v0.1.0)

StickyMD 的第一个公开版本是一张面向 Windows 11 的 Markdown 草稿：打开即写、自动保存，
原生渲染 Markdown 与数学公式，并能贴在桌面边缘按需出现。

## 主要功能

- Source、Preview、固定 50/50 Split 三种视图。
- CommonMark + GFM 原生渲染；Raw HTML 只显示原文，不执行。
- RaTeX/KaTeX-compatible 数学公式，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。
- `$` 工具把确认的 `\(...\)` / `\[...\]` 转换为 dollar math，并支持一次撤销。
- Split 默认按 Markdown source range 进行语义同步滚动，也可关闭同步。
- 当前源码的纯文本查找与替换：`Ctrl+F`、`Ctrl+H`、大小写开关，无正则。
- UTF-8 portable `note/note.md`、650 ms autosave、Ctrl+S、原子替换、恢复与外部修改冲突保护。
- 截图及 PNG/JPEG/WebP/GIF 图片粘贴、managed image 安全回收、Markdown + assets 导出。
- 左/右/上三边吸附、自动隐藏、hover 展开、托盘、置顶、主题、40–100% 透明度和内容缩放。
- Microsoft Pinyin 与 WeType 输入、撤销、剪贴板、选择和 Preview copy 路径。
- 一个目录一张草稿；同目录单实例，不同目录可以同时运行。

## 便携运行

发布物为 Windows 11 x64 portable ZIP，无安装器，不需要管理员权限。

`StickyMD.exe` 静态链接 MSVC CRT，并通过普通与 delay-load PE import 检查。公开版本没有
外置 Visual C++ 或 GNU 开发者运行库依赖，因此普通用户无需安装 Rust、Visual Studio、
C/C++ 编译器、Windows SDK 或独立 Visual C++ Redistributable。

程序目录必须允许当前用户写入；不要放在 `Program Files`。首次启动会在程序旁创建 `note/`。

## 隐私与网络

- 无账户、云同步、遥测、广告或自动更新。
- 无 runtime 网络客户端，不下载远程图片。
- 无 WebView、Electron、Tauri 或 JavaScript runtime。
- 所有便签数据保存在当前 Program Directory。

## 已知边界与验证缺口

- 仅支持 Windows 11 x64；不支持 Windows 10、ARM64、Linux 或 macOS。
- `v0.1.0` 没有 Authenticode 签名，Windows 可能显示 SmartScreen/信誉提示。
- Clean Windows 11 VM、真实双显示器同 DPI、真实双显示器 mixed DPI、运行中拔除当前显示器
  在 `v0.1.0` 发布时没有完成实机验收，已由维护者明确接受对应风险。
- Sleep/resume、RDP 重连和物理负坐标显示器属于未执行的非阻塞极端环境检查。
- 数学语法是 RaTeX/KaTeX-compatible，不是完整 LaTeX 文档编译环境。
- StickyMD 只编辑固定的 `note/note.md`，不提供文件树、多标签页或知识库功能。
