# StickyMD 0.1.2

本版本改进启动与预览中的重复工作，修复输入光标、列表预览和本地图片读取问题，并扩展开发验证工具。
发布状态、源码身份和附件以 GitHub 同名 Release 的实际记录为准。

## 输入与预览

- 修复长 preedit 文本和软换行场景中的 caret 可见性，减少输入位置落在视口外的情况。
- 保留列表内的段落和块结构，并为代码内容绑定对应字体。
- 拒绝通过重定向路径读取本地图片，保持便签目录与图片访问边界。
- 在一次 Preview 布局内共享不可变文字几何；图片占位几何稳定时，只刷新需要显示的 raster，减少重复全文排版。

## 启动与性能

- Source 与临时 preedit buffer 初始化时，省去随后会被丢弃的空文本字体匹配和排版。
- 空白行复用已解析的 Latin 字体；首选字体不可用时仍保留既有 fallback。
- 保持完整系统字体支持、首屏就绪条件、自动保存与 IME 边界。
- 启动聚焦沿用原有 winit 路径；普通 Win32 激活试验未证明稳定收益，已撤回。

开发期本机诊断及输入、搜索、滚动、预览、图片和缩放基线用于发现回归，不替代本次远端发布包的
完整资格化。跨轮启动数据受构建产物、缓存与系统调度影响，不把全部耗时下降归因于代码。
大文档首次预览仍可能出现可感知等待。

## 开发与发布工具

- 扩展 std-only Rust CLI，统一发布包内容与 README 生成、ZIP 最终落盘、Syft 缓存身份校验、
  阶段参数路由，以及远端 tag/草稿状态的拒绝规则。
- 增加本地未提交改动选测、检查原因说明和耗时日志汇总；保留 PowerShell 5.1/7 薄入口。
- 启动诊断分别保留 wall time、累计进程 CPU 和首笔输入事实，失败仍保留原始样本。
- 资源工具补齐 Zoom CPU 与窗口尺寸/样式对照；独立诊断不能生成正式资格化成功收据。

## 运行与升级

- Windows 11 x64 portable ZIP；程序目录需允许当前用户写入。
- 升级前保存并退出旧实例，备份并保留原目录的 `note/`，不要用空白便签覆盖已有数据。
- 仍采用 unsigned Authenticode 分发方式。请从官方 Release 下载，使用
  `Get-FileHash -Algorithm SHA256` 核对 `SHA256SUMS.txt`；不需要关闭系统防护。
- 产品没有网络客户端、云同步、遥测、自动更新或 WebView。
