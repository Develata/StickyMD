# StickyMD 0.1.0 — Draft Release Notes

> DRAFT ONLY. Version 0.1.0 and unsigned portable distribution are USER approved. Tag creation,
> remote push, draft Release creation and publication are not approved.

StickyMD is a native, portable Windows 11 Markdown scratchpad. It edits exactly one note beside the
executable, autosaves atomically, renders CommonMark/GFM and RaTeX math without a WebView, supports local
managed images and export, and provides the documented tray/docking desktop shell.

## Verification status

- Local automated qualification is bound to an exact source/artifact receipt.
- Startup and resource qualification is recorded in the exact-candidate evidence bundle.
- Real IME, visual, physical display topology, recovery and clean-VM rows require current-artifact human
  receipts before public release unless explicitly waived by the USER.

## Distribution

The planned artifact is an unsigned-Authenticode Windows 11 x64 portable ZIP. Windows may show a
SmartScreen/reputation warning. Verify `SHA256SUMS.txt`, the SPDX SBOM and GitHub attestations before
running; do not disable Defender or SmartScreen. No installer, updater, telemetry, runtime network client
or database is included.
