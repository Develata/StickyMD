# StickyMD 0.2.0

本版本把程序拆成三端共用的核心与各平台的薄壳，新增可在本机构建的 macOS 版，并修复保存与恢复路径上的
数据安全问题、窗口启动与窗口状态的若干缺陷，Markdown 解析器升级到 Comrak 0.59。
复制语义、底部提示条与预览文末留白（Phase 17）不在本版本中，属于下一版本。

## 数据安全

- 保存失败留下的临时文件 `note.md.tmp` 可能是较新文本的唯一副本：
  - 启动时，内容与 `note.md` 不同的有效临时文件总是作为恢复选择出现，不再因为较旧而被删除；
  - 载入外部内容后提交的保存，会取代仍在排队的临时文件清理，失败保存留下的临时文件不会被删掉。
- 恢复在移走不可用的 `note.md` 之前，先确认它仍是当初判定不可用的那个文件；等待选择期间被外部改过，就作为冲突处理，不再把新内容移走。
- 恢复移动文件时，只通过一个仅允许读取共享的句柄检查并改名同一个文件，拒绝该位置上的符号链接等非普通文件。
- 过大的 `note.md` 不再被自动读取或移动，恢复会提示先手动移开。
- 导出判断目标是否为工作便签、预览与导出解析相对图片，都改用便签目录的当前位置；运行中目录被移动替换时，导出不会覆盖真正的工作便签。
- 外部文件、恢复清理与保留的读写回执带上身份，过期的回执不再作用于新的操作。

## 启动与窗口

- 窗口启动失败不再静默以成功码退出：事件循环、窗口、绘制面、没有显示器或工具窗口身份失败时，结束启动、显示原因并以失败码退出；
  只影响外观的失败不再中止启动。
- 拖动结束、显示器变化后的位置，读回确认窗口确实到达后才写入配置；失败或 500 ms 内未确认时显示诊断，不写配置。
- 显示窗口在读回可见、未最小化之后才生效；被拒绝时保持隐藏、说明原因，可以重试。置顶在读回原生状态后才写入配置。
- 显示、隐藏、聚焦与置顶请求都有超时；显示器变化等待应用期间不确认位置；取消退出后按窗口当前状态恢复输入。
- 贴边收起后的感应条在各平台统一为 2 DIP；焦点回到收起的感应条时不再撤销临时置顶。
- 选中的工具栏按钮不再把背景画进缩放边带；工具栏空白处显示普通箭头；125% 缩放下 Split 同步按钮画在它的命中位置上。
- 透明度弹窗的数字、轨道与滑块随显示缩放；100% 外观不变，125%、150%、200% 下比例改正。

## 编辑与预览

- `$` 数学按钮先在 `$$`、`\[`、`\(` 与 `$` 公式内连接独占一行的 `=`，再转换分隔符；例如 AI 输出的 `\[ … \]` 中单独一行的 `=` 不再让按钮失效。
  公式以外的文字不变，再按一次不会再改。
- 只含链接引用定义的段落中的文字受保护，不会被当作公式连接；超过预览上限的文本先拒绝再处理；
  空列表项、空引用嵌套的标记行不再阻止跨越它们的 `$$` 连接。
- Markdown 解析器从 Comrak 0.54 升级到 0.59。

## macOS（本机构建，不提供下载）

- 新增 macOS 宿主（arm64，macOS 27 及以上），具备与 Windows 版相同的便签存储、贴边收起、菜单栏图标、剪贴板、Cmd 快捷键与退出屏障。
- 用本版本的源码执行 `apps/stickymd-mac/packaging/build-app.sh` 在本机构建 `.app`（ad-hoc 签名）。本 Release 不附 macOS 安装包。
- 帧通过 IOSurface 呈现；隐藏时释放帧缓冲。
- 验收情况见 `docs/acceptance-cases/phase-16.md`；该矩阵中的验收与人工确认绑定在发布前的构建上，改版本号后的 0.2.0 构建没有重跑。

## 内部结构

- 平台无关的应用层移到 `stickymd-app`，窗口外壳与控件移到 `stickymd-desktop`；Windows 程序成为实现原生能力的薄壳（Phase 15）。
  目标是行为与数据格式不变；迁移后的测试也在 Linux 与 macOS 上运行。

## 验证范围

- 源码 CI 与候选构建成功。晋升过程在 Windows runner 上按原候选构建的 artifact 重新校验 ZIP 与 SBOM 的精确字节，没有重新构建产品。
- 本候选的 Windows 资格化 readiness 为 **READY**，按发布清单逐项判定，未使用整版发布例外。
- 人工验收在 Windows 11 25H2（build 26200.9974）x64 上进行，绑定本候选的 EXE 与 ZIP。以下 15 项人工通过：
  - Microsoft 拼音与微信输入法的候选窗位置、遮挡、字体与 DPI 观感；
  - 左/右边缘贴靠与拖离；
  - 220×120 最小窗口下 Source、Preview、Split 三种模式的输入、滚动与选择；
  - 50/100/300% 缩放、透明度滑块、浅色/深色/跟随系统与运行时主题切换；
  - 代表性 Markdown、正确与错误公式、各类图片的预览观感；
  - 两份便携副本同时运行时各自的托盘显示/隐藏，以及 Windows 11 窗口外壳。
- 维护者豁免了一项人工场景：恢复与二次启动，以及退出时保存失败。
  - 点击、托盘与感应条恢复，以及从隐藏状态二次启动，已人工通过。
  - 从最小化状态二次启动与退出时保存失败，维护者在记录器之外做了观察，未形成正式记录。
  - 从 dock 收起状态二次启动未能记录：本版本的人工记录器仍按旧的 3 DIP 感应条判定，而产品已改为 2 DIP。记录器的修正留给下一版本。
- 单屏 100%、125%、150%、200% DPI 下的输入、预览、dock 与滚动条四项没有人工观察，由维护者按组豁免，不表述为通过。

**以下项目尚未验证，保留为 NOT TESTED：**

- 上一版本 Windows 11（24H2）。
- 干净 Windows 11 虚拟机首次运行。
- 双显示器同 DPI 与混合 DPI、运行中断开/重连显示器、RDP 重连、物理负坐标显示器布局。
- 睡眠恢复，以及从真实 junction 路径启动第二实例。
- macOS：0.2.0 构建的验收没有重跑（见上文 macOS 一节）。

## 下载、运行与升级

下载本 Release 的 `StickyMD-0.2.0-windows-x64-portable.zip`，解压后运行 `StickyMD.exe`。适用于 Windows 11 x64，无安装器。升级前保存并退出旧实例，备份原目录的 `note/`。

程序未做 Authenticode 签名，Windows 可能显示未知发布者或信誉提示。请从此官方 Release 下载，并核对下面的校验和及来源证明；无需关闭系统防护。
